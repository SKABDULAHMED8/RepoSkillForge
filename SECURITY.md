# Security Policy

RepoSkillForge contains AI instructions and references derived from software repositories.

Skills must not instruct agents to steal credentials, bypass authentication, exfiltrate secrets, deploy malware, disable security controls without authorization, or perform destructive actions without appropriate safeguards.

Do not publish API keys, passwords, tokens, private keys, or other secrets in issues or pull requests.

Report malicious instructions, compromised dependencies, or exposed credentials privately through GitHub's security reporting mechanism when available.
