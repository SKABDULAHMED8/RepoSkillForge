# Skills

Every directory under `skills/` is an independently usable RepoSkill.

Required:

```text
skills/<name>/SKILL.md
```

Optional:

```text
references/
examples/
scripts/
evals/
```

Keep `SKILL.md` focused. Put detailed material in supporting files.

Status values used by the registry:

- `draft`
- `tested`
- `stable`
- `deprecated`
